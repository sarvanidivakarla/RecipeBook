# RecipeBook

**RecipeBook** is a simple JavaScript web app that lets users search for recipes by name, fetches data from the [TheMealDB API](https://www.themealdb.com/), and displays recipe overviews, ingredients, instructions, and video links.

---

## Features

- Search for recipes by name  
- View recipe overview (image, category, area)  
- Display detailed ingredients and measurements  
- Read step-by-step cooking instructions  
- Watch the YouTube video recipe (if available)  

---

## Technologies Used

- HTML, CSS, JavaScript  
- [TheMealDB API](https://www.themealdb.com/) for recipe data

---

## How to Run Locally

1. Clone or download this repository.

2️. Open the project folder.

3️. Open `index.html` directly in your web browser (no server setup needed).

4️. In the search box, type any recipe name (e.g., `Pasta`, `Chicken`, `Cake`) and click **Search**.
